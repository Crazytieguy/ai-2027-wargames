# AI 2027 Wargames

A desktop application for tracking and visualizing AI R&D progress multipliers over time, used by [AI Futures](https://ai-futures.org/) for their tabletop exercises. See their published forecast at [ai-2027.com](https://ai-2027.com/).

## Features

- **Dual-window interface**: Data editor and real-time chart visualization
- **Dynamic data management**: Add/remove columns (labs) and rows (time periods) with customizable dates
- **Live chart updates**: Log-scale visualization with semantic AI capability labels
- **Data persistence**: Auto-caching, save/load JSON files, keyboard shortcuts

Built with Tauri 2.0, React, TypeScript, Recharts, and Tailwind CSS
